# Admin features

As an admin of Tallis & Reeve, I need a list of all users and categories of the idea app, so that I can change their roles

## Acceptance criteria
- [ ] The user list is accessible only to admins
- [ ] The user list shows all users with their name, email, role and office
- [ ] The user can be simulated for tests
- [ ] The category list is accessible only to admins
- [ ] The category list shows all categories with their name and description
- [ ] A category can be edited, added or marked as inactive

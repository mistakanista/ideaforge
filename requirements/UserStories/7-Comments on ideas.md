# Comment on an idea

As an employee of Tallis & Reeve, I want to comment of ideas, so that it can be improved and easier be implemented

## Acceptance criteria
- [x] The comments are listed with the newest on top
- [x] The comments include a text, the date of the comment and the user who commented
- [x] it is possible to also answer to a comment
- [x] a comment can be deleted by the creator as long as no one has answered to the comment
- [x] no comments on confidential ideas
- [x] the comments are opened on a click on the button or link show comments, with number of comments in brackets
- [x] there is a pagebrowser for ideas with more than 10 comments

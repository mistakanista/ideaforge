# Pipeline dashboard

As an employee, reviewer or admin of Tallis & Reeve, I want to see, browse and filter all the ideas, so that I can find the ones I am interested in

## Acceptance criteria
- [ ] There is a list of all ideas with the newest on top, the declined ones are hidden, as well as the implemented
- [ ] There is a filter option to view ideas by category
- [ ] There is a filter option to view ideas by office
- [ ] There is a search functionality to find specific ideas
- [ ] There is a filter option for votes
- [ ] There is a filter or search option for users, especially I want to filter my ideas

## Status: open

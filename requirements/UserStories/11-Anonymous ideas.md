# Create an anonymous idea submission feature

As an admin or employee of Tallis & Reeve, I want to be able to submit ideas anonymously, so that I can share my thoughts without revealing my identity

## Acceptance criteria
- [x] There is a checkbox in the idea submission form to submit an idea anonymously
- [x] These ideas are clearly marked as anonymous 
- [x] the name of the submitter is not displayed
- [x] users still see their own anonymous ideas in the my ideas filter
- [x] ideas can be confidential and anonymous at the same time, then the reviewer do not see the creator of the confidential idea

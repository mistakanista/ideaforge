# ideaforge

The repo follows the software development lifecycle.

It is structured in requirements, design, develop and deploy

## Prerequisites
- Node.js 20+ (https://nodejs.org/en/download/)
- npm 9+ (comes with Node.js)

## Start the app

- go to build/frontend
- copy the env.example to env
- the mock settings will be used (seed data)
- ask the developers for the supabase settings if you want to use the supabase backend
- run npm install
- npm run dev        # the app starts on http://localhost:5800
- there is also a README.md in build/frontend with more details about the frontend and how to test it

# ideaforge

The repoo follows the software development lifecycle.

It is structured in requirements, design, develop and deploy

## Start the app

- go to build/frontend
- copy the env.example to env
- fill in supabase and the credentials if you want to run it against the supabase database otherwise mock data will be used
- run npm install
- npm run dev        # the app starts on http://localhost:5800
- there is also a README.md in build/frontend with more details about the frontend and how to test it
